# Titanic survival prediction

MLDS 400 Homework 3: reproducible logistic regression workflows in Python and R.

The repository uses `main`, `develop`, and separate feature branches. Code is
organized under `src/python/` and `src/r/`. Downloaded competition files belong in
`src/data/`, which is excluded from Git and the Docker build context. Generated
results belong in `outputs/` and are also excluded from Git.

Data source: [Kaggle Titanic competition](https://www.kaggle.com/competitions/titanic/data).
